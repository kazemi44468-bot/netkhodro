# نت‌خودرو | سامانه مدیریت ناوگان

نمونه اولیه فارسی و راست‌چین برای مدیریت خودروها و موتورسیکلت‌های شرکت، تخصیص به ادارات و اشخاص، سوابق تحویل، نگهداری، هزینه‌ها، کارکرد، استهلاک و تعدیل هزینه با شاخص طلا.

## اجرا
- فایل `index.html` را مستقیماً در مرورگر باز کنید.
- برای انتشار، GitHub Pages را روی شاخه `main` و پوشه ریشه (/`) تنظیم کنید.
- اطلاعات نسخه نمونه در LocalStorage همان مرورگر ذخیره می‌شود.

## امکانات نسخه 0.1
- داشبورد مدیریتی و عملیات سریع
- بانک خودرو و موتورسیکلت با شناسه خودکار CAR-0001 و MOT-0001
- پرونده وسیله و سوابق تخصیص
- ثبت تحویل، تحویل‌گیری و انتقال
- ثبت تعمیرات، سرویس و سررسید بعدی
- ثبت هزینه به تومان و نرخ طلای زمان هزینه
- ثبت کارکرد و مأموریت با کنترل توالی کیلومتر
- برآورد اولیه استهلاک خط مستقیم و ضریب کارشناسی
- تعدیل هزینه‌های تاریخی با نرخ دستی طلای ۱۸ عیار
- گزارش‌های مدیریتی، تعریف ادارات و اشخاص
- خروجی و بازیابی نسخه پشتیبان JSON

## محدودیت‌های مهم نمونه اولیه
این نسخه یک Prototype سمت مرورگر است و پایگاه داده مرکزی، ورود امن، نقش‌ها و مجوزهای واقعی، همگام‌سازی چندکاربره، ثبت امضای دیجیتال، اتصال خودکار قیمت طلا، مدیریت فایل‌های اسناد و اعلان زمان‌بندی‌شده ندارد. داده‌ها فقط در مرورگر و دستگاه فعلی ذخیره می‌شوند. برای بهره‌برداری سازمانی باید Backend و پایگاه داده مرکزی، احراز هویت، مجوزهای سمت سرور، ثبت رویدادهای ممیزی و پشتیبان‌گیری سمت سرور پیاده‌سازی شود.

## نکته محاسباتی
محاسبه استهلاک فعلی یک برآورد مدیریتی نمونه بر اساس عمر مفید و ضریب است؛ جایگزین رویه حسابداری یا نظر کارشناس رسمی نیست. تعدیل با طلا نیز «معادل طلایی هزینه» را نشان می‌دهد و به‌تنهایی شاخص تورم یا ارزش واقعی اقتصادی محسوب نمی‌شود.
